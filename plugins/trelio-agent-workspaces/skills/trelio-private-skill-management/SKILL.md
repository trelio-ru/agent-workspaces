# Приватные навыки компании Trelio

Это короткий bootstrap-маршрутизатор. Актуальный контракт публикации находится
в schema и результатах текущих management tools `trelio-remote-skills`. Следуй
им буквально и не воспроизводи здесь форматы релиза, поля, лимиты, E2EE-механику
или package validation.

1. Выбери актуальный read-only plan tool для создания навыка либо следующего
   релиза. Перед вызовом прочитай его полную schema; не угадывай отсутствующие
   аргументы и не используй старый план.
2. План ничего не публикует. Покажи существенный preview, все предупреждения и
   точный `planHash`, затем остановись ради отдельного явного подтверждения.
   Исходная просьба «создай» или «опубликуй» это подтверждение не заменяет.
3. Только после отдельного подтверждения используй соответствующий current apply
   tool с теми же `planId`, `planHash` и `confirmed=true`. Истёкший план либо
   конфликт текущего состояния требует нового plan и нового подтверждения.
4. При неоднозначном результате сначала установи live state через разрешённый
   read/idempotency path из tool result; не создавай новый план вслепую.
5. Не обходи этот контур браузером, прямым HTTP, записью в БД или другим MCP.
   При setup/access blocker передай причину и следующий шаг из точного результата,
   не выводя права, transport или recovery самостоятельно.
6. После успеха сообщи только подтверждённые result facts и дай точный
   `settingsUrl`, если он возвращён.
